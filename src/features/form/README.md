# Form Feature

This directory contains the core logic for the dynamic form engine.

## Responsibilities

- **Dynamic Rendering**: Renders form components based on JSON schema generated by the LLM.
- **Provider Agnostic**: Uses the currently selected LLM provider (Gemini, OpenAI, Anthropic, etc.) for generation.
- **State Management**: Manages form answers and conversation history.

## Key Components

- `PromptFormEngine`: The main orchestration component.
- `DynamicForm`: Renders the form fields based on the schema.
- `FieldRenderer`: Renders individual fields based on type.
