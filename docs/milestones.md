# Brompt Development Roadmap

This document outlines the phased development plan for **Brompt**, breaking down the Product Requirements Document (PRD) into actionable milestones. Each milestone builds upon the previous one to deliver a complete, high-efficiency prompt engineering toolkit.

## Milestone Checklist

- [x] **[Milestone 1: Foundations](./milestones/01-foundations.md)**
  - Basic SPA Layout (Header, Sidebar, Main Content)
  - Tailwind CSS Configuration
  - API Key Modal UI
  - Project Cleanup & Setup

- [x] **[Milestone 2: Dynamic Engine Implementation](./milestones/02-dynamic-engine.md)**
  - C1 Engine Integration
  - Dynamic Form Components (Text, Select, Toggle, Slider)
  - JSON Schema Management
  - Form State Orchestration

- [x] **[Milestone 3: LLM Integration](./milestones/03-llm-integration.md)**
  - Google Gemini API Connection
  - "Generate" Button & Workflow
  - Markdown Result Rendering
  - "Copy to Clipboard" Functionality

- [x] **[Milestone 4: Persistence & History](./milestones/04-persistence-history.md)**
  - LocalStorage Service Implementation
  - Secure API Key Persistence
  - Prompt History Sidebar & Search
  - Draft Auto-saving

- [ ] **[Milestone 5: Internationalization & Polish](./milestones/05-internationalization-polish.md)**
  - i18n Support (English / Portuguese)
  - "Reset Form" with Confirmation
  - Final UI/UX Refinements
  - Loading States & Feedback

## Tracking Progress

As development proceeds, mark tasks as complete in the corresponding milestone file. This roadmap serves as the high-level overview of project status.
